# Website Style Guide

A style guide page I made for Codecademy's Full-Stack Engineer path. The idea is to lock in a site's look before building it, so every page uses the same colors, fonts, and components.

Live site: https://ktforge.github.io/website-style-guide-codecademey-full-stack/

Mine covers:

A color palette (IndianRed, LightSalmon, Gold, Fuchsia, and Indigo)
Fonts, using Cantarell, Fira Sans, and IBM Plex Serif from Google Fonts
Text styles for main headings, subheadings, body text, and links
Button styles

## Running it

Clone the repo and open `index.html` in your browser.
